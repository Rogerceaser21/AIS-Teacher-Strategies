# AIS Teacher Strategies · The Learning Environment Playbook

Staff-facing playbook: six strands, thirty classroom setups, and a searchable library of
around 150 named techniques, inspired by *Dynamically Different Classrooms* (Claire Gadsby
and Jan Evans, Independent Thinking Press). All content is AIS-authored practice in our own
words; read the book for the original techniques, case studies and photographs.
